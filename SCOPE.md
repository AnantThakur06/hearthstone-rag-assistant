# Hearthstone Coffee Co. — RAG Knowledge Assistant

## What this project is
A standalone web app that reads Hearthstone Coffee Co.'s own documents and answers customer questions in the shop's warm, on-brand voice (in text, not voice).

## What it does (scope)
- Answers customer questions using only the business's three documents, in a friendly, on-brand tone.
- Runs as a simple web app the client opens in a browser and types questions into.
- Shows the exact source in the documents for every answer, so it can be checked — nothing is invented from outside the documents.

## Documents it uses
- The FAQ
- The returns / shipping policy PDF
- The brewing guide

## Not included in this phase
- No Shopify embedding
- No product pages
- No taking orders
